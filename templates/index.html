Nodes you own

A small board, an old laptop or a spare phone becomes an exit node. Plug it in, enter the code on the case, and it joins your network.

Standard interfaces

SOCKS5 and HTTP CONNECT, so existing tools work unchanged — curl, browsers, scrapers, anything that speaks a proxy.

Nothing hidden

No SDKs bundled into other apps, no silent enrolment. Node owners see what their device relays and can stop it any time.

Private by design

Traffic stays encrypted end to end through the tunnel. The orchestrator routes bytes; it does not read them.

Open source

AGPLv3, in Rust. Read the relay, the protocol and the orchestrator — then run your own.

Built to be small

A node runs on a few watts. An ESP32 is enough for light traffic; a single-board computer handles the rest.
