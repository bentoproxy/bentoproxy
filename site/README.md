# Bento landing page

Static commercial landing page for the Bento boxes (Wire and Air), routes, the AI agents MCP/API, Earn and the membership.
No build step: open `index.html`, or serve the folder (`python3 -m http.server -d site`).

Prices, the $3 membership, the $0.10/GB payout and the `mcp.` / `api.` / `proxy.bentoproxy.com` addresses are placeholders.
